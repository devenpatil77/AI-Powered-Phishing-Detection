# AI Powered Phishing Email Detection

## Overview
This project detects phishing emails using Machine Learning.

## Technologies
- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Logistic Regression
- Pandas

## Features
- Detect phishing emails
- Confidence score
- NLP preprocessing
- Streamlit web interface

## Dataset
800 email dataset

## Accuracy
100% on the provided dataset

## Run

pip install -r requirements.txt

streamlit run app.py
